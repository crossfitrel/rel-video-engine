# כתוביות הראל — אפליקציית הכתוביות המקומית

מעלים סרטון → מתקנים את הטקסט → מקבלים אותו חזרה עם כתוביות צרובות בסגנון המותג.

## איך מפעילים
**דאבל-קליק על `▶ הפעל כתוביות R.E.L.command`**
השרת עולה והדפדפן נפתח לבד בכתובת `http://127.0.0.1:5111`.
(להפעלה ידנית: `python3 server.py` מתוך התיקייה הזו.)

לסגירה: סוגרים את חלון הטרמינל שנפתח.

## איך משתמשים
1. בוחרים במפורש **אושיה** או **מועדון**.
2. גוררים סרטון לחלון (או לוחצים לבחירה).
3. הסרטון מתומלל אוטומטית — מתקנים רק שגיאות תמלול/שמות.
4. לוחצים **"צרוב כתוביות והורד"** ומקבלים את הסרטון המוכן.

## פרופילי מותג (חוק ברזל)
- אושיה: Heebo · לבן · מתאר כחול `#0077B6`.
- מועדון: Assistant ExtraBold · לבן · מתאר אדום `#871d1f`.

בשניהם: מילה אחת בכל פעם · תחתון-מרכז · בלי נקודות/פסיקים.
השמע המקורי נשאר כמו שהוא. סיבוב אוטומטי של סרטוני אייפון מטופל.

## איך זה עובד (מאחורי הקלעים)
נשען על אותו מנוע של מערכת העריכה (`../tools`):
- **faster-whisper** (venv `~/.rel-whisper`) — תמלול ותזמון מילים אמיתי
- **align_reconcile.py** — ממזג את הטקסט המתוקן שלך עם התזמון האמיתי
- **חוקי הקיבוץ/הצבעים/הפונט** מ-`captions_build.py`
- צריבה ב-`captions_overlay.py` (PIL → שכבת overlay ב-ffmpeg), כי ה-ffmpeg המקומי בלי libass

## קבצים
- `server.py` — השרת המקומי (Flask)
- `index.html` — הממשק
- `captions_overlay.py` — רינדור וצריבת הכתוביות
- `▶ הפעל כתוביות R.E.L.command` — הפעלה בקליק
- קבצים זמניים נשמרים ב-`~/Library/Caches/REL-Captions` (מחוץ ל-iCloud, נמחקים אוטומטית אחרי יומיים)

> דרישה: המאק צריך להיות דלוק והאפליקציה פועלת בזמן השימוש. אין צורך באינטרנט לתמלול (המודל מותקן מקומית).

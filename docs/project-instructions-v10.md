## איך מתחילים צ'אט
1. לטעון את הסקיל `rel-social-video-editor` (ליבה + מפת references; קוראים רק את ה-reference של השלב).
2. עבודה בפועל = סשן ענן: `add_repo crossfitrel/rel-video-cloud` → clone → `bash cloud/bootstrap.sh` → פקודות הסקיל עם `$REL_PY`.
3. בדיקות: `$REL_PY tools/baseline.py` (פלט קצר + דיף מול הקודמת).
4. שינוי קוד → commit + push לריפו. שינוי מאסטר/CORE של הסקיל → `tools/skill_pack.py build` → התקנה מחדש.

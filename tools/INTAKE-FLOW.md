# INTAKE-FLOW — קליטת קבצי גלם מקומית (בלי העלאה למאנדיי)

> **למה זה קיים:** ההעלאה של קבצי הווידאו הגולמיים *למאנדיי* נכשלת כל הזמן (קבצים כבדים / API לא יציב), והיא הייתה צוואר הבקבוק של כל התהליך. הפתרון: **הקבצים נשארים מקומיים מההתחלה.** מאנדיי שומר רק טקסט — בריף, תסריט וסטטוס — וזה אף פעם לא נכשל.

---

## הזרימה החדשה (4 שלבים)

```
1. קליטה (מקומי, אפס אינטרנט)
   הראל מכניס את קבצי הגלם לתיקייה לפי מחלקה/חודש/סרטון
   → תוכן שיווקי/{מחלקה}/{חודש}/{שם הסרטון}/   (raw/ אופציונלי)

2. שיוך גלם↔בורד (מקומי)
   match_intake.py משווה את תיקיית החודש לפריטי "מוכן לעריכה" בבורד הסושיאל
   → יודע בדיוק איזו תיקייה שייכת לאיזה פריט (matched / needs_review / missing / orphans)

3. משיכה מקומית (מקומי)
   הסוכן קורא את הקובץ ישירות מהדיסק. לא נוגעים במאנדיי בשביל הווידאו.

4. העלאה אחת ל-Descript (השלב היחיד שדורש אינטרנט)
   import_media (direct upload) + descript_put.sh → ואז זרימת העריכה הרגילה.
```

**מה השתנה מול הישן:**
| | ישן (נכשל) | חדש |
|---|---|---|
| איפה הגלם | מועלה למאנדיי | מקומי בתיקיית המחלקה |
| איך נכנס ל-Descript | get_assets → URL מאנדיי → import_media | import_media (direct) + `descript_put.sh` |
| כשל אינטרנט | מאבד את כל הצעד | הקובץ בטוח מקומי, חוזרים על העלאה אחת בלבד |
| תפקיד מאנדיי | קובץ + בריף + סטטוס | **רק** בריף + תסריט + סטטוס (טקסט) |

## שתי דרכים להכניס קבצים (שתיהן מקומיות)

**א. דרופ ישיר לתיקייה (מומלץ — אפס העלאה דרך צ'אט):**
הראל גורר את קבצי הגלם ב-Finder לתוך התיקייה הנכונה. iCloud מסנכרן, והסוכן רואה אותם. עובד גם אם האינטרנט מקרטע — הקבצים על הדיסק.

**ב. העלאה דרך הצ'אט:**
הראל מעלה את הקבצים לסוכן + אומר מחלקה/חודש/שם סרטון. הסוכן מתייק אותם למבנה הנכון.

> בשתי הדרכים, מה שהסוכן צריך לדעת כדי לתייק: **מחלקה + חודש + שם הסרטון.** אם החודש לא צוין — ברירת מחדל חודש הפרסום הנוכחי, והסוכן מציין מה הניח.

## מבנה התיקיות (זהה לניתוב התוצרים הקיים)

```
תוכן שיווקי/
  {מחלקה}/
    {חודש שנה}/            ← לאירועים: בלי חודש, נושא ישירות
      {שם הסרטון}/
        raw/              ← קבצי הגלם נכנסים לכאן
        {שם הסרטון - סופי.mp4}   ← התוצר הסופי (קיים מקודם)
```

**מחלקות (מתוך `folder-routing.json` — מקור אמת):**
- `קרוספיט אריאל` (כולל קבוצות נשים + ילדים) — לפי חודש
- `שיקום בתנועה` (R.E.L Therapy) — לפי חודש
- `REL Performance` — לפי חודש
- `REL Throwdown {שנה}` — אירוע, בלי חודש
- `Community Games {שנה}` — אירוע, בלי חודש

זיהוי מחלקה: label מדויק → id/index → aliases. אותו היגיון של `resolve_output_path.py`.

## כלים

- **`match_intake.py --items items.json --pretty`** — משייך פריטי "מוכן לעריכה" לתיקיות הגלם המקומיות לפי מחלקה/חודש/שם. מחזיר matched / needs_review / missing / orphans. דטרמיניסטי — לא מנחש, דו-משמעי עולה להראל.
- **`descript_put.sh <file> "<upload_url>"`** — PUT רובסטי (retry, ‎`--bg` לקבצים כבדים) של קובץ מקומי אל ה-upload_url ש-`import_media` מחזיר. מחליף את ה-URL של מאנדיי.
- **`resolve_output_path.py`** — מחשב את נתיב תיקיית הסרטון (אותו נתיב משמש גם ל-`raw/`).
- **`finish_local.py` / `captions_build.py`** — שלב הגימור המקומי (ללא שינוי).

## אילוצי Sandbox (חשוב לסוכן)

- **יצירה/העתקה** לתוך `תוכן שיווקי/` מה-sandbox — ✅ עובד (bash mkdir/cp, Write).
- **מחיקה/הזזה** מה-sandbox — ❌ חסום ("Operation not permitted"). לכל move/delete/rename → **Desktop Commander** (`start_process` עם rm/mv על נתיב ה-Mac האמיתי).

## הערת כנות אחת

"בלי תלות באינטרנט" מתקיים לקליטה, לתיוק ולגימור — הכל מקומי. השלב היחיד שעדיין מקוון הוא דחיפת הקובץ ל-Descript, כי שם מנוע העריכה (AI Agent + תמלול). אבל זו **העלאה אחת ישירה ואמינה** עם retry — לא ההעלאה השבירה למאנדיי. הקובץ תמיד בטוח על הדיסק קודם, אז כשל רשת לא מאבד עבודה — פשוט חוזרים על אותה העלאה.

# rel-thumbnail-creator — מנוע Thumbnail ממותג

## תפיסת על

לכל ריל שעולה לסושיאל מצרפים **קאבר/תמונה-ממוזערת** קבועה במותג: רקע = פריים מתוך הסרטון, ועליו קופסה
אדומה חצי-שקופה עם כותרת קצרה ומושכת (ולעיתים תת-כותרת). עד היום זה נעשה ידנית בקנבה
(`canva.com/design/DAGggkrYTNY`). הסקיל הזה **מחליף את העבודה הידנית** בהפקה מקומית אוטומטית (PIL),
זהה בעיצוב, מהירה, חינמית ועקבית.

**איפה זה יושב:** שלב חדש בפייפליין של `rel-social-video-editor` — **שלב 8.3.7**, מיד אחרי גיבוש הקופי
(8.3) ולפני מייל האישור (8.4). הקאבר מצורף למייל האישור, ואז מועלה כקאבר בקומפוזר של Metricool.

## 🔒 עקרונות נעולים — חובה (כתובים כאן, עצמאית; אל תסתמך על זיכרון שיחה)

1. **מקור הפריים = הסרטון *לפני הכתוביות*.** תמיד לחלץ מ-`_work/{שם הסרטון}/EXPORT.mp4` (ה-recut המקומי,
   טרום צריבת כתוביות), או מקובץ `*טרום כתוביות*.mp4` אם קיים. **אסור** לחלץ פריים מ"סרטון מוכן"
   (`file_mm402fp7`) — בו הכתוביות כבר צרובות והן ייכנסו לקאבר. זו הסיבה היחידה שהשלב הזה לא משתמש בקובץ הסופי. **אם האקספורט הנקי לא נשמר — לייצא מחדש מ-Descript (`publish_project`, חינם) ולהוריד; לעולם לא ליפול לקובץ עם הכתוביות (הראל 25.6).** מומלץ לבחור את הקאבר **לפני** צריבת הכתוביות בפייפליין — אז הפריים הנקי זמין ממילא. **⚠️ fallback ללא קרדיט (אם אין מקור נקי ואי אפשר render): טשטוש רצועת הכתובית בפריים לפני הקופסה** — `ffmpeg -i FRAME -filter_complex "[0:v]crop=1080:190:0:1420,boxblur=30[bl];[0:v][bl]overlay=0:1420"` ואז `thumbnail_build --band-center 0.80` (הקופסה מכסה את האזור המטושטש → הכתובית נעלמת). הקופסה שקופה 70% — כתובית לבנה חדה מבצבצת דרכה, לכן חובה לטשטש קודם. אומת 25.6 (חתירה/בוקס/עוריות/ילדים). הערה: בסרטוני-טיפ הדיבור רציף → אין פריים נטול-כתובית, לכן הטשטוש הכרחי.
2. **פלט: PNG — יחס הקאבר חייב להתאים ליחס *הסרטון*, אחרת שמירת Metricool נתקעת.** ⚠️ קריטי:
   - **סרטון 9:16 (אנכי, רוב הריילס) → קאבר 1080×1920** (`--width 1080 --height 1920`, ברירת מחדל).
   - **סרטון ריבועי 1:1 (כמו "אימון המוקדמות" 1920×1920) → קאבר 1080×1080** (`--width 1080 --height 1080`).
     **9:16 על סרטון ריבועי תוקע את שמירת ה-Metricool — אסור.** בדוק את יחס הסרטון לפני (`ffprobe`).
   - **תמיד ממלא את היחס בלי מסגרות שחורות:** מקור עם letterbox שחור צרוב → המנוע חותך אוטומטית ועושה
     **blur-fill** (רקע מטושטש ממלא + תוכן חד במרכז). בדיקת QA: שולי הקובץ לא שחורים. (פידבק הראל 23.6.)
3. **קופסה אדומה: `#871d1f` בשקיפות 70%**, רוחב מלא (edge-to-edge), קצוות חדים.
4. **כותרת: `Ploni Bold` לבן.** **תת-כותרת: שרשרת פונטים בת 3 שלבים לפי כיסוי תווים**
   (עודכן 24.7.26) — כל שלב הוא קובץ "Specimen Subset" (תת-סט מוגבל של תווים):
   1) **`Studentit`** (`Studentit-Specimen-Subset.ttf`) — 27 אותיות עבריות + רווח בלבד.
   2) **`Bagira`** (`Bagira-Specimen-Subset.otf`) — משלים: עברית + רווח + ספרות 0-9 +
      פיסוק/סימנים נפוצים (! # $ % . , : ? ₪ € וכו'). עדיין בלי לועזית.
   3) **`Ploni Bold`** — כיסוי מלא (כולל לועזית), רשת ביטחון סופית.
   תת-הכותרת כולה נבחרת לפי הפונט הראשון בשרשרת שמכסה את **כל** התווים שלה (לא מערבבים
   פונטים בתוך שורה) — הלוגיקה ב-`thumbnail_build.py`. **תת-כותרת אופציונלית** — לפעמים רק כותרת.
5. **טקסט מבוסס-תוכן בלבד.** הכותרת/תת-כותרת נגזרות מההוק/התסריט/התמלול של אותו סרטון — **בלי להמציא
   הטבות/מבצעים** ובלי טענות שלא נאמרו (תואם כלל 8.3 של הפייפליין). עברית בלבד.
6. **בחירת פריים אוטומטית "מושכת עין":** פנים פרונטליות + חדות + בהירות שפויה, ופנים בחלק העליון של הפריים
   כך שהקופסה בשליש התחתון **לא תכסה את הפנים**.
7. **בלי לוגו, בלי טקסטים גרפיים נוספים** מעבר לכותרת/תת-כותרת. (תואם כלל "אין לוגו / אין טקסטים גרפיים".)

## מבנה התבנית (פרמטרים מדויקים — נעולי-מותג)

```
קנבס            : 1080 × 1920 (cover-fit לרקע)
קופסה           : מלבן רוחב-מלא, צבע #871d1f (135,29,31), אלפא 0.70 (=178/255)
מרכז אנכי קופסה  : 0.725 × גובה  (שליש תחתון; ניתן לכוונון --band-center)
ריפוד אנכי קופסה : 40px מעל/מתחת לבלוק הטקסט
כותרת           : Ploni Bold, לבן, auto-fit (התחלה 132px, מתכווץ עד שנכנס לרוחב), שוליים 70px
תת-כותרת        : Studentit → Bagira → Ploni Bold (לפי כיסוי תווים), לבן, ~0.60 מגודל הכותרת (מינ' 40px)
מרווח כותרת↔תת  : 6px
יישור           : ממורכז (anchor mm)
RTL             : raqm (libraqm) — מעבירים טקסט לוגי כמו-שהוא עם direction="rtl"; raqm עושה bidi+shaping
```

**⚠️ RTL — לקח קריטי (תיקון 23.6):** Pillow כאן בנוי **עם raqm**. לכן מעבירים את הטקסט **הלוגי כמו שהוא**
עם `direction="rtl"` ו-raqm מסדר את הכיוון. **אסור להפעיל `python-bidi`/`get_display` מעל raqm** — זה גורם
**היפוך כפול** והטקסט יוצא הפוך ולא קריא (הבאג ההיסטורי). `get_display` הוא fallback **רק** כשאין raqm
(`features.check("raqm")==False`). מאומת ויזואלית.

קבצי הפונט הסטטיים שמורים ב-`tools/thumbnail/fonts/` (PloniBold.otf, Studentit-Specimen-Subset.ttf,
Bagira-Specimen-Subset.otf + DanaYadAlefAlefAlef-Normal.otf / PlaypenSansHebrew-*.ttf כחלופות
היסטוריות בשרשרת fallback אם קובץ חסר).

## תהליך ריצה (שלב 8.3.7)

> כל הריצה בסנדבוקס. נתיב הסנדבוקס: `/sessions/*/mnt/Social Video Editing System/`.

**1. אתר את מקור הפריים (לפני כתוביות):**
```
SRC = _work/{שם הסרטון}/EXPORT.mp4          # עדיף
# אם אין: חפש _work/{שם הסרטון}/*טרום כתוביות*.mp4
```
אם אין אף מקור טרום-כתוביות → **לעצור ולדווח** (אסור לחלץ מהקובץ הסופי עם הכתוביות).

**2. בחר פריים אוטומטית:**
```
cd tools/thumbnail
python3 frame_select.py "{SRC}" --out /tmp/thumb_{slug}
# פלט: best.png (1080×1920) + candidates.jpg (contact sheet לאימות עצמי)
```
לאמת ויזואלית את `best.png` (Read) — פנים נקיות, בלי כתוביות, חד. אם לא מתאים — להריץ שוב עם
`--step 0.3` או לבחור ידנית פריים מ-`candidates.jpg` (timestamp) ולחלץ עם ffmpeg.

**3. נסח כותרת + תת-כותרת (מבוסס תוכן):**
- מקור: ההוק/המסר של הפריט ב-Monday (`long_text_mkzk9556` / `long_text_mkzkwwgk`), או התמלול
  (`export_transcript` — חינם, בלי credit). כותרת = 2-4 מילים חדות; תת-כותרת = שורת המשך קצרה (אופציונלי).
- בקול המותג (ישיר, אנושי). **בלי הטבות מומצאות.** שאלה/סקרנות עובדות מצוין ("כאב בקרסול?", "הטעות שכולם עושים").

**4. בנה את ה-Thumbnail:**
```
python3 thumbnail_build.py \
  --frame /tmp/thumb_{slug}/best.png \
  --title "{כותרת}" \
  --subtitle "{תת-כותרת}"      # להשמיט אם רק כותרת \
  --out "{PROJECT_FOLDER}/_work/{שם הסרטון}/thumbnail.png"
```

**5. תייק + אמת:**
- שמור עותק לתיקיית הדליברי של הסרטון (`{מחלקה}/{חודש}/{שם הסרטון}/{שם הסרטון} - thumbnail.png`)
  דרך Desktop Commander (תיקיית-האב מחוץ ל-mount), לצד הסרטון הסופי.
- Read את ה-PNG הסופי לאימות (כותרת קריאה, לא חותכת פנים, קופסה ב-70%).

**6. הזרקה לפייפליין:**
- צרף את ה-PNG למייל האישור (8.4) כך שהראל רואה את הקאבר לפני התזמון.
- **העלאה כקאבר ב-Metricool = ידני בקומפוזר** ("Upload video thumbnail" → בחירת `thumbnail.png`).
  ⚠️ **Metricool API לא תומך בקאבר וידאו** (אין שדה cover/thumbnail ב-`createScheduledPost` — אומת 23.6.2026).
  לכן זו פעולת-קומפוזר ידנית, כמו מיקום/תיוג/CTA-אינסטגרם בשלב 8.5.1.
  ⚠️ **גם דרך דפדפן (Chrome) זה בלתי אפשרי — לא "אופציה עתידית".** Metricool פותח חלון-קבצים **נייטיב של מערכת ההפעלה** (showOpenFilePicker; אין `<input type=file>` ב-DOM להזרקה), שאוטומציית דפדפן לא יכולה לשלוט בו. אומת 26.6.2026 — נוסו `file_upload`, לכידת input ביצירה, JS patch על `HTMLInputElement.prototype.click`, וקליק מדויק — **כולם נכשלו (NO_CAPTURE)**. **מסקנה: הקאבר מיוצר מקומית ונמסר להראל להעלאה ידנית (≈20ש לפוסט). לא לבזבז זמן על אוטומציית דפדפן לקאבר.**

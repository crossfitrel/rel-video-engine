## שתי ההכרעות

### 1. איפה מרכיבים בירול? → **צריבה מקומית (ffmpeg overlay), לא ב-Descript**

הבירול יוצא מ-Descript לגמרי והופך לשכבת גימור מקומית — בדיוק כמו הכתוביות.

**למה:**
- **סדר נכון** — הראל רוצה: עריכה ברמת הקטעים קודם → בירול → כתוביות. צריבה מקומית מרכיבה בירול על ה-EXPORT הנקי, באותו שלב של הכתוביות. מודל מנטלי אחד.
- **דטרמיניסטי וקל לתיקון** — in/out מדויק לכל בירול; להזיז/להחליף/לקצר = עריכת JSON והרצה מחדש. בלי agent, בלי credits, בלי תמלול מחדש.
- **עוגן מדויק** — כבר יש לנו טיימקודים ברמת מילה מהכתוביות; הבירול מתעגן עליהם.
- **אודיו בטוח מעצם הבנייה** — פס הדיבור לא נגוע, הבירול מושתק (`-an`).
- **מסיר את החוליה החלשה** — ה-Descript agent היה הכשל ההיסטורי בבירולים. מוציאים אותו ממסלול הבירול.

Descript נשאר למה שהוא טוב בו: **החיתוך של הדיבור** (הסרת טייקים/מילוי/סידור). הבירול עוזב את Descript.

### 2. איך מבדילים סוגים ויודעים איפה כל אחד? → **Tag בשם + Anchor בתמליל**

החולשה = ניחוש איזה קליפ זה מה, ואיפה הוא הולך. הפתרון: להפוך את שניהם למפורשים ודטרמיניסטיים.

**א. מוסכמת שם סמנטית.** כל בירול נושא את הקטגוריה בשם הקובץ — לא רק המילה "בירול":
```
בירול__<תגית>__<תיאור חופשי>.mp4
```
התגית = הקטגוריה. אין ניחוש איזה קליפ זה — הקובץ מצהיר. (`tools/broll-tags.json` יחזיק לכל מחלקה את רשימת התגיות הקנוניות + מילים נרדפות, כדי שהתאמה תהיה עמידה.)

**ב. עוגן בתמליל (Anchor).** לכל תגית יש **משפט עוגן** — המשפט בדיבור שהבירול ממחיש. אחרי החיתוך הנקי והיישור למילים, המפה מאתרת את חלון הזמן של משפט העוגן ומשבצת שם את הבירול:
- מתחיל ~0.3ש **אחרי** תחילת משפט העוגן (שהצופה ישמע את ההקשר קודם), נגמר לפני הביט הבא.
- חוקי ברזל מהקאנון: אף פעם לא על 0:00 / ה-Hook, אף פעם לא על ה-CTA (פנים על המסך), בירול תמיד מושתק.
- אורך הבירול = min(אורך הקליפ, חלון העוגן). קליפ ארוך מהחלון → אמצע-הקליפ 2.5-3ש.

**ג. `broll-map.json` לכל סרטון** — הנכס היחיד לבדיקה ולתיקון:
```json
[{"tag":"...", "anchor":"משפט מהתמליל", "start":null, "end":null, "source":"path|MISSING"}]
```
נוצר כתוכנית מראש (אפס credit); הטיימקודים מתמלאים אחרי החיתוך והיישור. הראל מפיל קליפ בשם עם התגית המתאימה → `source` נפתר לבד וסקריפט ה-overlay משבץ. שום ניחוש מחדש.

**ד. טיפול בבירול חסר.** המפה מייצרת את כל המשבצות עם עוגנים; `source: MISSING`. החיתוך והכתוביות ממשיכים **בלי** בירול. כשהקליפים מגיעים מתויגים — פקודה אחת מרכיבה אותם על ה-EXPORT הטרום-כתוביות וצורבת כתוביות מחדש. שום דבר אחר לא רץ מחדש.

## מתכון ה-overlay המקומי (מושתק, אנכי, blur-fill לפי הצורך)
```
ffmpeg -i EXPORT_precaption.mp4 -i בירול.mp4 -filter_complex \
 "[1:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,setsar=1,trim=0:D,setpts=PTS-STARTPTS[bv]; \
  [0:v][bv]overlay=0:0:enable='between(t,START,END)'[v]" \
 -map "[v]" -map 0:a -c:a copy -c:v libx264 -crf 20 -pix_fmt yuv420p out.mp4
```
בירול אנכי-מלא = crop; בירול לרוחב = blur-fill (רקע מטושטש) במקום crop. תמיד בלי אודיו מהבירול.
